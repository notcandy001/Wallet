# Wallet

A local-first digital wallet for India (iOS first, Android planned). "Wallet" is the product name for now; it lives in one place (`Brand.name`) so it is easy to change.

Wallet organises passes (loyalty, membership, tickets, boarding passes, general passes, document references, visual card representations). It does **not** make payments, is **not** a UPI app, and does not verify passes with issuers. See `docs/decisions/0003-trust-model.md`.

## Status (honest)
Written in a Linux environment with no Swift toolchain, so **nothing here has been compiled or run yet**. See `docs/ROADMAP.md` and `docs/DEVELOPMENT_ENVIRONMENT.md`.

## Build on a Mac (Xcode 16+, iOS 17+)
```sh
open apps/ios/Wallet.xcodeproj      # pick an iPhone simulator, press Run
cd apps/ios/WalletCore && swift test   # optional: domain tests
```
`Wallet.xcodeproj` was generated by `scripts/generate_xcodeproj.py` (hand-built, never opened in Xcode yet). If Xcode reports a project problem, run that script again or use `project.yml` with XcodeGen. Set your own bundle identifier before running on a device.

## Layout
- `apps/ios/WalletCore` – Swift package: domain model, validation, search, persistence (testable without UI)
- `apps/ios/Wallet` – SwiftUI app: design system, wallet home, pass details, add/edit, settings
- `docs/` – specification, decisions, roadmap
- `apps/android`, `backend`, `packages/*` – reserved, not started
