# 0002 Local persistence
Status: accepted for v0.1. A single versioned JSON file in Application Support, written atomically with complete file protection on iOS, behind a `PassRepository` protocol. Why not SwiftData/Core Data: small data set, easy to test and export, no framework-version risk while unable to compile. Unreadable files are moved aside (`passes.corrupt-*.json`), never overwritten; files from a newer schema are left untouched. Revisit if collections grow large or relational queries are needed. Open question: whether the file should be excluded from device backups.
